# Runs

One folder per game played, in `runs/<config>/<seed>/`, each holding `story.txt` (the one to read), `pirates-log.txt`, `events.jsonl`, `replies.jsonl`, `config.json` and `manifest.json`. `silent/7/` is the silent crew's seed 7 under the v2 rules, played with `treasure-island run configs/silent.toml --seed 7`. `v2/0/` is the first v2 pilot, six pirates on `adaption/deepseek-v4-flash` playing `configs/pilot/v2.toml` with seed 0: they pinned the cave on game turn 5 and all got in, so it is the evidence that the default board is too easy for a model crew. `v2/0-2/` is the second, four pirates on the board calibration then picked (10x10, readings off by up to 4) with 12288 thinking tokens: pirate-3 dug up the cave on game turn 42, its own turn 11, after the crew split the search and ruled squares out from each other's shared readings, with no reply cut off. It was stopped by hand after the find, then played again from its saved replies with a spending cap of 0, so it ends cleanly where the live run stopped. `reference-silent/` is the real game's reference game under the v2 rules, with `events.jsonl`, `story.txt` (read this one), `pirates-log.txt` and `config.json`, and it replays like any other run. `silent-seed-7/` is a first-rules game, played before readings, free talk and orders: it stays committed as it was but leaves the replay checks (see its README). The nine folders named after `configs/incentives/` cells (`none-off/`, `control/` and the rest) hold every game of the incentives sweep, those played again included, the evidence behind `experiments/incentives-findings.md`; one game per cell is on the replay list. Every game the findings count replays; attempts they don't count may show as failures in `make replay-all`. Committed ones are evidence, homed by a row in the spec that needs them; `scratch/` and `smoke/` stay uncommitted. This guide has no `Implements:` line because nothing under `runs/` may carry one.
